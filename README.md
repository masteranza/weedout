# Weedout AI for Youtube

Weedout is a Safari extension for macOS that removes videos YouTube itself labels **Made with AI** from your home feed, search results, related videos, playlists, and Shorts—before you click them.

[Get Weedout on the Mac App Store ($1.99, one-time purchase)](https://apps.apple.com/app/weedout-ai-for-youtube/id6804296217?mt=12)

## Why Weedout

- Uses YouTube's own disclosure labels, not guesses, heuristics, or a community blocklist.
- Remove mode hides labeled videos; Dim mode fades and tags them so you can verify first.
- Optional auto-skip for labeled Shorts.
- No accounts, analytics, tracking, or data collection.
- Verdicts stay cached on your Mac; the extension only talks to `youtube.com`.

## Honest limit

Weedout can only filter videos YouTube labels. Unlabeled AI content will still get through. As YouTube labels more content, Weedout catches more.
